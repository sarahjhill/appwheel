# App icons

Put official app icons here, then type the file name (for example `netflix.png`)
in the **Icon** box for that app in the admin (App Wheel > Common apps).

Before adding a company's icon, check its brand or press guidelines allow it.
Square PNG or SVG files work best, at least 128 x 128 pixels.

Apps without an icon show a coloured tile with their initials instead.
